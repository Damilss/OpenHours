```bash
python -m venv .venv
source .venv/bin/activate  # On Windows use: .venv\Scripts\activate
pip install -r requirements.txt
```

# OpenHours — Backend

FastAPI backend handling file parsing, embeddings, RAG pipeline, and analytics.

---

## Requirements

- Python 3.10+
- A running local LLM server (Ollama, LM Studio, etc.) — get details from your teammate
- Supabase project with schema applied — get details from Person 4

---

## Setup

### 1. Create a virtual environment

```bash
cd backend
python -m venv venv
```

### 2. Activate the virtual environment

**Windows:**
```bash
venv\Scripts\activate
```

**Mac/Linux:**
```bash
source venv/bin/activate
```

You should see `(venv)` at the start of your terminal prompt. Always activate before running anything.

### 3. Upgrade pip and setuptools first

```bash
python -m pip install --upgrade pip setuptools
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Install Whisper (video/audio parsing)

Whisper must be installed separately due to a known build issue with the PyPI version:

```bash
python -m pip install git+https://github.com/openai/whisper.git
```

Whisper also requires **ffmpeg** for audio/video processing:
- **Windows:** Download from [ffmpeg.org](https://ffmpeg.org/download.html) and add to PATH
- **Mac:** `brew install ffmpeg`
- **Linux:** `sudo apt install ffmpeg`

> You can skip Whisper for now if you're not testing video uploads yet.

### 6. Set up environment variables

Copy the example env file:

```bash
cp .env.example .env
```

Fill in your values:

```env
# Local LLM Server — get these from your teammate running the LLM
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=local
CHAT_MODEL=llama3
EMBEDDING_MODEL=nomic-embed-text

# Supabase — get these from Person 4
SUPABASE_URL=your_supabase_project_url
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

## Running the Server

```bash
uvicorn main:app --reload
```

Server runs at `http://localhost:8000`

---

## Verifying It Works

Once running, open `http://localhost:8000` in your browser — you should see:
```json
{"status": "ok", "message": "OpenHours API is running"}
```

Open `http://localhost:8000/docs` for the interactive API explorer (auto-generated by FastAPI). You can test endpoints directly from the browser here.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Health check |
| `POST` | `/upload` | Upload a file (PDF, PPTX, video) — parses, embeds, stores |
| `POST` | `/ask` | Student asks a question — returns guided AI answer |
| `GET` | `/analytics/{course_id}` | Professor analytics — struggle topics + summary stats |
| `POST` | `/courses` | Create a new course |
| `GET` | `/courses/{professor_id}` | Get all courses for a professor |
| `DELETE` | `/courses/{course_id}` | Delete a course and all its data |

## Common Issues

**`venv` not recognized / uvicorn not found**
Make sure you activated the venv first (`venv\Scripts\activate` on Windows). You need to do this every time you open a new terminal.

**`No module named 'pkg_resources'` when installing whisper**
Use the GitHub install instead: `pip install git+https://github.com/openai/whisper.git`

**4000+ files showing as git changes**
The `venv/` folder got tracked by git. Run:
```bash
git rm -r --cached backend/venv
```
Then commit. The `.gitignore` will prevent this going forward.

**Server starts but `/ask` returns errors**
Check that your `.env` file exists and has valid values for `LLM_BASE_URL` and Supabase keys.
